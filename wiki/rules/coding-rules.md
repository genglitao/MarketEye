# 编码准则

> 本文件定义项目的编码行为准则，所有开发者必须遵循。

*最后更新: 2026-10-19*

***

## 1. 编码前思考

**不要假设。不要隐藏困惑。呈现权衡。**

在实现之前：

- **明确说明假设** — 如果不确定，询问而不是猜测
- **呈现多种解释** — 当存在歧义时，不要默默选择
- **适时提出异议** — 如果存在更简单的方法，说出来
- **困惑时停下来** — 指出不清楚的地方并要求澄清

## 2. 简洁优先

**用最少的代码解决问题。不要过度推测。**

- 不要添加要求之外的功能
- 不要为一次性代码创建抽象
- 不要添加未要求的"灵活性"或"可配置性"
- 不要为不可能发生的场景做错误处理
- 如果 200 行代码可以写成 50 行，重写它

**检验标准：** 每一行修改都应该能直接追溯到用户的请求。

## 3. 精准修改

**只碰必须碰的。只清理自己造成的混乱。**

- 在编辑现有代码时：
  - 不要"改进"相邻的代码、注释或格式
  - 不要重构没坏的东西
  - 匹配现有风格，即使你更倾向于不同的写法
  - 如果注意到无关的死代码，提一下 —— 不要删除它
- 当你的改动产生孤儿代码时：
  - 删除因你的改动而变得无用的导入/变量/函数
  - 不要删除预先存在的死代码，除非被要求

**检验标准：** 每一行被修改的代码都应能直接追溯到用户的具体需求。

## 4. 目标驱动执行

**定义成功标准。循环验证直到达成。**

- 将指令式任务转化为可验证的目标：
  - "添加验证" → "为无效输入编写测试，然后让它们通过"
  - "修复bug" → "编写重现 bug 的测试，然后让它通过"
  - "重构X" → "确保重构前后测试都能通过"
- 对于多步骤任务，说明一个简短的计划：
  - \[步骤] → 验证：\[检查]
  - \[步骤] → 验证：\[检查]
  - \[步骤] → 验证：\[检查]

## 5. 本项目编码约定

### 5.1 依赖与运行

- **只用 Python 标准库**（`tkinter` / `urllib` / `json` / `ctypes` / `datetime` / `threading`），**禁止引入第三方包**。这是项目的核心卖点，任何 `pip install` 都是回归。
- 单文件程序：`ticker.pyw` 承载全部逻辑，新增功能以方法形式扩展，不拆文件、不建包。
- `.pyw` 后缀必须有——双击启动不能弹黑框。

### 5.2 ctypes 调用 Win32 的铁律

```python
# 必须显式声明类型，否则句柄 > 2^31 时抛 OverflowError
u.GetAncestor.argtypes = [wintypes.HWND, wintypes.UINT]
u.GetAncestor.restype = wintypes.HWND
```

> **血泪教训**：曾因 `GetWindowRgn` 未声明 `argtypes`，`OverflowError` 被外层 `except: pass` 吞掉，
> 导致几何自愈整段静默失效，表现为「时好时坏」（句柄大小随会话变化）。**任何吞异常的 `except` 都必须写日志。**

### 5.3 窗口圆角：禁止 SetWindowRgn

> **已被验证的缺陷**：只要窗口被 `SetWindowRgn` 设过区域，之后再缩放窗口，新露出的区域**永远不会被重绘**（恒为黑块）。
> 实测 `RedrawWindow` / `SetWindowPos(SWP_FRAMECHANGED)` / `withdraw+deiconify` / 延迟重设区域全部无效。

圆角必须用**颜色键透明**实现：`-transparentcolor` 设为 `KEY`（`#FE02FD`），画布自绘圆角矩形，四角压 KEY 遮罩。
`apply_round()` 方法保留为空实现，仅作兼容占位。

### 5.4 DPI 与尺寸

- 字体一律用**正数点数**（如 `("Microsoft YaHei UI", 9)`）；负数在 Tk 8.6 的 DPI 缩放下会失真
- 所有像素尺寸走 `self.px(v)`（内部乘 DPI 缩放系数），**禁止硬编码像素值**
- 布局计算与命中判定都要用同一套 `px()` 换算，否则 150% 缩放下热区会错位

### 5.5 异常与日志

- UI 线程内的异常不得直接抛出（会卡死事件循环），须捕获后记 `ticker.log`（`_dbg()`），正常路径零开销
- 网络请求必须有超时（默认 5s），失败降级为「保留上次数据 + 标题栏圆点变红」，不得清空列表

### 5.6 修改后的验证要求

| 改动类型 | 最低验证 |
| --- | --- |
| 行情解析 | 用真实接口跑一次，核对字段索引与编码（GBK） |
| 绘制/布局 | 截图按 `GetWindowRect` 物理坐标裁剪，量化检查关键区域像素 |
| 窗口行为（缩放/折叠/置顶） | 实测操作 + 截图，确认无黑块、无残影 |
| 配置结构 | 旧配置文件仍能正常加载（向后兼容） |
