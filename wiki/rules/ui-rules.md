# 界面 UI 规范

> 本文件定义「盯盘君」桌面悬浮窗的视觉与交互规范，是 PROTO / SDD §3.5 的唯一取值依据。
> **所有颜色、字号、间距、圆角必须取自本表，禁止引入表外新值。**

*最后更新: 2026-10-21*

***

## 一、设计 Token

### 1.1 说明

本项目没有 CSS 变量体系（tkinter 直接取值），Token 以 **Python 常量** 的形式存在于 `ticker.pyw` 头部：

| Token 载体 | 位置 | 用途 |
| --- | --- | --- |
| `THEMES["dark"]` / `THEMES["light"]` | 文件头部 | 主窗口配色，两套主题键名完全一致 |
| `KEY` | 文件头部 | 颜色键透明用的品红，仅用于遮罩 |
| `WatchlistDialog.C_*` | 对话框类 | 自选管理面板配色（深色专用，不随主题切换） |
| `px()` 方法 | `Panel` 类 | 逻辑像素 → 物理像素的唯一换算入口 |

> **硬性规则**：新增任何界面元素，颜色从 `THEMES` 取值，尺寸经 `self.px()` 换算。**禁止**直接写 `#RRGGBB` 或裸像素数字。

## 二、窗口规范

### 2.1 色彩使用规则

- **红涨绿跌**（中国市场习惯，不可反置）：`up` 用于涨幅 > 0，`down` 用于涨幅 < 0，`flat` 用于 0 值与无数据。
- 颜色只表达**涨跌语义**，不表达「好坏」——不要用红色表示错误、绿色表示成功（状态圆点除外）。
- 正文禁止纯黑 `#000000` / 纯白 `#FFFFFF`（遮罩与按钮文字除外），必须取 `text` / `name` / `sub` 三级。
- 层级通过**亮度差**表达：`text` > `name` > `sub`，不要靠字号堆叠制造层级。

### 2.2 字体排印

| 用途 | 字体族 | 字号 | 字重 |
| --- | --- | --- | --- |
| 窗口标题 | Microsoft YaHei UI | 10 | bold |
| 标的名称 | Microsoft YaHei UI | 9 | normal |
| 价格 / 涨跌幅 | Consolas | 9 | bold |
| 分组名 | Microsoft YaHei UI | 8 | normal |
| 时钟 | Consolas | 9 | normal |
| 对话框标题 | Microsoft YaHei UI | 10 | bold |
| 对话框正文 / 按钮 / 列表 | Microsoft YaHei UI | 9 | normal |
| 对话框次要说明 | Microsoft YaHei UI | 8 | normal |

- 字体族选择顺序：`Microsoft YaHei UI` → `Microsoft YaHei` → `SimHei`；数字：`Consolas` → `Cascadia Mono` → `Courier New`。
- **字号必须为正数点数**（如 `9`）。Tk 8.6 在 150% DPI 缩放下，负数字号会被二次缩放导致文字过大。
- 价格与涨跌幅**必须用等宽字体**，保证小数点与正负号纵向对齐。

### 2.3 间距与对齐

- 所有文字与元素间距取 `px()` 换算后的整数值，不使用 0.5 等半像素。
- 列表采用**三区右对齐**布局：

```
| 14px  名称（左对齐，超出截断加 …）        价格（右对齐 @ CW-86）  涨跌（右对齐 @ CW-8） |
|       分组名（8pt，sub 色）──────────────────────────────────  （line 色细线）        |
```

- 名称超长时截断并保留末尾 `…`，不得换行（行高固定 25）。
- 数字区域宽度不设固定像素，靠右对齐锚点保证纵向成列。

### 2.4 圆角与边框

- 窗口圆角半径固定 `body_r = 16` 逻辑像素，四角**必须**透出桌面（颜色键透明实现）。
- **禁止使用 `SetWindowRgn` 裁剪窗口**（与缩放冲突，详见 `coding-rules.md §5.3`）。
- 内部元素一律无边框（`highlightthickness=0, bd=0`）；分组线用 1px 细线、`line` 色。
- 滚动条**不使用系统控件**，自绘为 8px 宽胶囊，无边框、无箭头。

### 2.5 组件规范

#### 标题栏

- 高度 34，背景 `head`。
- 左侧：状态圆点（直径 6，居中偏左 14）+ 标题文字（10pt bold，左对齐 @ 27）。
- 右侧：时钟 `HH:MM:SS`（9pt Consolas，右对齐 @ W-13），**精确到秒**。
- 圆点颜色语义：绿 `#12B76A` = 交易中 / 灰 `flat` = 休市 / 红 `#E5484D` = 连接失败。
- 双击标题栏 = 折叠/展开；折叠后窗口高度 = 34。
- 折叠态标题栏中部为**轮播区**（标题右侧 8px 起、时钟左侧 10px 止）：指数名称（9pt normal，`text` 色）+ 两个半角空格 + 涨跌幅（9pt Consolas bold，涨跌配色同列表行）。空间不足时不渲染，不遮挡标题与时钟。

#### 列表行

- 行高 25，无斑马纹、无悬停高亮（悬浮窗场景避免视觉噪声）。
- 单击 = 选中（供右键菜单定位），双击 = 打开浏览器行情页。
- 列内容：名称（`name`）、价格（`up`/`down`/`flat`）、涨跌幅（同价格色，格式 `+0.00%`）。

#### 分组标题

- 行高 20，文字 8pt `sub` 色，后接细线延伸至内容区右边缘。
- 分组可折叠时，展开/收起图标放在分组名前（若有），不使用箭头字符堆叠。

#### 滚动条

- 轨道：宽 8，`line` 色，纵向从 `head_h` 起，高度 = `vis_cc`。
- 滑块：宽 8，`bar` 色，高度按 `track_h × min(1, 可见/总高)` 解析计算，最小 22。
- 仅当内容超高时显示；不高时滑块与轨道均隐藏。
- 可直接拖动滑块，拖动优先级高于窗口缩放。

#### 右键菜单

- 使用 tkinter 原生 `Menu`，深色配色（背景 `#3B4A63` 悬停、前景 `#FFFFFF`）。
- 菜单项顺序固定：立即刷新 / ─ / 显示列 ▸ / 轮播间隔 ▸ / 不透明度 ▸ / 置顶（勾选）/ 折叠展开 / 恢复自适应高度 / ─ / 管理自选 / 编辑配置 / 重新加载 / 开机自动启动（勾选）/ ─ / 退出。
- 分隔线用 `add_separator()`，不手工画线。

#### 自选管理面板

- 尺寸约 520×600（逻辑像素），圆角 16，背景 `#1B2231`，整体不透明度 0.985。
- 结构：标题栏（可拖动）→ 搜索框 → 结果列表 → 已选列表 → 底部按钮组。
- 按钮三态：主按钮（`#3B82F6` 底 / 白字）、次按钮（面板底 / `#EAEFF8` 字）、危险按钮（面板底 / `#E5484D` 字）。
- 双击搜索结果 = 添加；双击已选项 = 改名。

### 2.6 层级与遮挡

窗口内部存在**三层绘制关系**，新增元素前必须确认落在正确层：

| 层 | 载体 | 说明 |
| --- | --- | --- |
| 底层 | `cv`（主 Canvas） | 背景、标题栏、分组线、滚动条轨道与滑块 |
| 中层 | `cc`（内容 Canvas，真实子窗口） | 标的名、价格、涨跌幅。**子窗口永远盖在主画布之上** |
| 顶层 | 四角 KEY 遮罩 | 把越出圆角的元素擦成透明 |

> **推论**：滚动条必须画在 `cc` **右侧让出的 10px 条带内**，否则会被 `cc` 永久遮挡。
> 内容区底部也要让出 `body_r` 高度（`vis_cc = vis_h - body_r`），否则底部圆角会被 `cc` 切成直角。

### 2.7 交互热区与光标

| 区域 | 范围 | 光标 | 行为 |
| --- | --- | --- | --- |
| 上/下边 | 距边 ≤ 5px | `size_ns` | 垂直缩放 |
| 左/右边 | 距边 ≤ 5px | `size_we` | 水平缩放 |
| 四角 | 距两边均 ≤ 5px | `size_nw_se` / `size_ne_sw` | 双向缩放 |
| 标题栏 | 除边缘外 | `fleur` | 拖动窗口 |
| 列表区 | 行内 | `hand2` | 单击选中、双击打开 |
| 滚动条滑块 | 滑块矩形内 | `sb_v_double_arrow` | 拖动滚动 |

- 热区判定优先级：**角落 > 边缘 > 内容**。
- 缩放过程中不得触发重建（用轻量重排），松手后才落盘尺寸并重排。

### 2.8 DPI 适配

- 启动时声明 DPI 感知（`SetProcessDpiAwareness(2)`），并按 `GetScaleFactorForDevice` 取缩放系数。
- 所有逻辑尺寸经 `px(v) = round(v × scale)` 换算，**命中判定与绘制必须用同一套换算结果**。
- 支持的缩放档位：100% / 125% / 150% / 200%，四档均需目视验证无错位、无截断。
- 窗口位置存盘为**物理像素**，恢复时钳制到当前屏幕范围内（防止换显示器后窗口跑出屏幕）。

### 2.9 状态与空值

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 价格与涨跌显示 `--`，色 `flat`，圆点灰 |
| 刷新中 | 不改变显示内容（不闪烁、不清空） |
| 网络失败 | 保留上次数据，圆点变红，不弹窗、不报错 |
| 无自选 | 列表区显示一行 `sub` 色提示「右键 → 管理自选，添加标的」 |
| 标的下市/代码错误 | 该行显示 `--`，不影响其他行 |

- **禁止**使用弹窗提示刷新失败（悬浮窗不该抢焦点）。
- 空状态文案统一用 `sub` 色、9pt，不使用插画或图标。

### 2.10 动效

- 本产品**不做动效**（无淡入淡出、无滑动动画）。悬浮窗的核心诉求是「随时扫一眼」，动画只会增加干扰。
- 唯一允许的即时反馈是颜色变化（涨跌、圆点状态）与光标形态变化。
- 折叠/展开为瞬时切换，不做高度过渡。
