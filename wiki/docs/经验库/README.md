# 经验库

本目录存放开发过程中积累的经验教训，遵循**简洁优先**原则。

## 经验模板

```markdown
## {经验名称}

**问题**：一句话描述

**做法**：
1. ...

**效果**：量化或定性描述

**适用场景**：一句话
```

## 设计原则

- 每条经验不超过 200 字
- 问题 → 做法 → 效果，三部分足矣
- 一条经验解决一个具体问题
- 允许「半条经验」——只有做法和问题也行
- 贡献者 5 分钟写一条，查阅者 30 秒判断是否相关

## 分类说明

| 目录 | 内容 |
|------|------|
| `全局/` | 跨模块通用的经验 |
| `需求/` | 需求分析相关 |
| `编码/` | 编码经验（分前后端） |
| `测试/` | 测试相关 |
