# UI Designer 原型技能

本技能负责**界面原型生成**，是被 prd-skill 调用的环节技能之一。

> 本项目产品是 **Windows 桌面悬浮窗**（tkinter 绘制），没有网页 UI。
> 原型仍以**单文件 HTML 模拟**呈现——因为浏览器里改一个像素比改代码重跑快得多，适合做视觉评审；
> 但原型只用于**确认视觉与布局**，不参与产品构建，最终实现以 `ticker.pyw` 的 Canvas 绘制为准。

## 触发条件

- prd-skill 步骤4，用户确认需要生成原型时触发
- 不可由用户直接调用

## 前置条件

| 条件 | 说明 |
|------|------|
| ui-rules.md | 必须存在，定义 Token（配色、字体、尺寸、圆角、不透明度）与组件规范 |
| PRD 文档 | 必须存在，提供功能需求与界面入口（§2.4 界面功能架构） |
| 上一版本原型 | **优先读取上一个版本的 PROTO 文件**作为基础，在其结构上迭代；若不存在则从头生成 |
| PROTO 命名 | 遵循文档规范，格式 `PROTO-盯盘君-{功能名}-v{版本号}.html` |

## 工作流程

### 步骤1：读取输入

1. **读取上一版本原型**（迭代版本必须）：
   - 在 wiki.md 或同目录下找到上一版本的 PROTO 文件
   - 通读其结构：CSS 变量、区块划分、文字层级、颜色用法
   - 新版本在此基础上修改/新增，不重新设计已有部分
2. 读取 [ui-rules.md](../../rules/ui-rules.md) 获取设计系统：
   - 配色 Token（深色 / 浅色两套，键名一致）
   - 字体排印（字号、字重、等宽数字）
   - 尺寸 Token（标题栏 34、行高 25、圆角 16 等）
   - 组件规范（标题栏、列表行、分组标题、滚动条、右键菜单、管理面板）
   - 绘制层级规则（哪些元素会被子窗口遮挡）
3. 读取当前 PRD 文档，提取：
   - 界面入口与触发方式（§2.4）
   - 功能需求与交互流程（§3）
   - 验收标准中的交互细节（§5）
   - 与上一版本的差异（变更记录 §1.2）

### 步骤2：生成原型

**迭代原则**（存在上一版本原型时）：
- **继承不变部分**：窗口框架、标题栏、列表区、配色变量直接复用，不重写
- **仅修改变更部分**：对照 PRD 变更记录，只改动本版本新增或调整的区域
- **保持风格连续**：不引入 ui-rules.md 之外的新颜色、新字号、新圆角

**技术要求**：
- 单文件 HTML（内联 CSS + JS），浏览器直接打开，**零外部依赖**（不用 CDN、不用图标库）
- 画布尺寸 = 窗口真实逻辑尺寸（如 `455 × 460`），居中放在深灰／浅灰背景上，模拟桌面
- 窗口本体用 `border-radius: 16px` 还原圆角，`opacity` 还原半透明
- CSS 变量承载 Token，命名与 `THEMES` 键名一致（`--bg` / `--head` / `--line` / `--text` / `--name` / `--sub` / `--up` / `--down` / `--flat` / `--bar`）
- 字体栈：中文 `"Microsoft YaHei UI", "Microsoft YaHei", sans-serif`；数字 `Consolas, "Cascadia Mono", monospace`
- 数字列用 `font-variant-numeric: tabular-nums` 或等宽字体保证对齐
- 必须覆盖全部交互状态：默认 / 悬停 / 按下 / 拖拽中 / 折叠 / 空数据 / 加载中（`--` 占位）/ 连接失败（红点）
- 右键菜单、管理面板用绝对定位浮层模拟，点击可切换
- 缩放热区用半透明边框示意（可加开关按钮显隐），帮助评审确认 5px 热区位置

**设计原则**：
- 严格遵循 ui-rules.md 的 Token，**不引入表外值**
- 布局反映真实窗口结构（标题栏 34 + 列表区 + 滚动条 10px 条带）
- 红涨绿跌，不可反置

### 步骤3：交付

产出 `PROTO-盯盘君-{功能名}-v{版本号}.html`，与 PRD 放在同一版本目录下，并在 wiki.md 中登记。

## 注意事项

- 原型是 PRD 的视觉附属物，**不是产品代码**——不要把它拼进 `ticker.pyw`
- 不引入 ui-rules.md 之外的设计元素；缺定义时明确指出缺失项并建议补充
- HTML 与原程序存在渲染差异（抗锯齿、字体度量），**像素级对齐以实际程序截图为准**
- 若原型中的交互依赖 Windows 特性（拖动缩放、颜色键透明、置顶），在原型旁标注「需实机验证」，不要试图在 HTML 里完全复刻
