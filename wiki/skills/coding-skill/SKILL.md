# Coding 编码技能

本技能负责**按设计文档进行编码实现**，是被sdlc-skill调用的环节技能之一。

## 触发条件

- sdlc-skill 评估后认为需要实现功能
- Bug修复（代码实现与设计不一致）
- 纯技术变更（有设计文档时）

## 前置条件

| 场景 | 前置依赖 |
|------|----------|
| 业务需求实现 | 需求文档(PRD) + 设计文档(SDD)，版本对齐 |
| 纯技术变更 | 设计文档(SDD) |
| Bug修复 | 需求文档(PRD)（用于定位问题） |

## 工作流程

### 步骤1：检查文档状态

```
├─ 业务需求实现
│     ├─ 是否有PRD？
│     │     ├─ NO → 终止，提示先走prd-skill
│     │     └─ YES → 继续
│     └─ 是否有SDD？
│           ├─ NO → 终止，提示先走sdd-skill
│           └─ YES → 版本是否对齐？
│                    ├─ NO → 终止，PRD与SDD版本不一致
│                    └─ YES → 继续
│
├─ 纯技术变更
│     └─ 是否有SDD？
│           ├─ NO → 终止，提示先走sdd-skill
│           └─ YES → 继续
│
└─ Bug修复
      └─ 是否有PRD？
            ├─ NO → 建议先补充PRD
            └─ YES → 继续
```

### 步骤2：读取设计文档

- 业务功能：读取 PRD + SDD，确认版本对齐；读取 PROTO（如存在），PROTO 是用户确认后的正式交付物，确保实现效果与原型一致
- 纯技术变更：读取 SDD
- Bug修复：读取 PRD 定位问题位置

### 步骤3：读取规范文件

读取以下规范文件，确认编码行为规范：

- [编码准则](../rules/coding-rules.md)
- [UI 规范](../rules/ui-rules.md)（**强制**，管控窗口配色、字体排印、间距、圆角、绘制层级、交互热区）

### 步骤4：编码实现

以 SDD 第 10 章任务清单为执行列表，逐项实现：

1. 读取任务清单，确认所有任务状态为 `待实现`
2. 按任务编号顺序逐项执行：
   - 根据 `代码位置` 定位目标文件
   - 根据 `变更类型` 执行对应操作：`新增` → 新增代码、`修改` → 修改已有代码、`删除` → 删除或标记废弃
   - 完成后将该任务状态更新为 `已完成`
3. 全部任务完成后，确认清单中无 `待实现` 状态的任务

输出：

- 实现完成的代码
- 已更新的任务清单（全部 `已完成`）

### 步骤5：独立审核

启动**独立的 Agent 实例**，依据 [编码准则](../rules/coding-rules.md) 和 [UI 规范](../rules/ui-rules.md) 对变更代码进行合规性审核。审核通过后流程结束，等待用户指示下一步。产生代码的 AI 不得自行审核。

## 注意事项

- 严格按SDD文档实现，不做额外改动
- 如发现设计文档问题，通知sdlc-skill回退到设计环节
